# 插图教程：把插画放进「鸣潮主题」

这个仓库**只有代码、配色、动效、字体和徽章图标，没有任何画师的插画**。不放图也能用，背景会显示纯色和动效。
想要完整效果，需要你自己准备图片放进去。整个过程分五步：

1. [取得原作者同意](#第-1-步取得原作者同意)（**必须**）
2. [下载原图](#第-2-步下载原图)
3. [把图放进插件](#第-3-步把图放进插件)（三种方法任选）
4. [让 DSH 读到新图](#第-4-步让-dsh-读到新图)
5. [（可选）调整构图和署名](#第-5-步可选调整构图和署名)

最后有[常见问题](#常见问题)。

> ⚠ **先读[免责声明](../README.md#免责声明)。** 插画版权属于画师本人。
> 下载、使用（包括只放在自己电脑里自用）、修改（裁剪、抠图、转格式）、传播之前，**都必须先取得原作者的同意**。
> 没有得到同意，就不要用这张图，换成别的你有权使用的图片。

## 第 1 步：取得原作者同意

### 1.1 找到原作和画师

打开 [图片清单](图片清单.md)，每一行都有：

| 列 | 意思 |
| --- | --- |
| 放到 | 图片在插件里的位置和文件名，例如 `assets/bg/srune.webp` |
| 作品 ID | Pixiv 作品编号，例如 `142480181` |
| 原作 | 点开就是原作页面 `https://www.pixiv.net/artworks/作品ID` |
| 画师 | 点开是画师的 Pixiv 主页 |
| 备注 | 要用第几张、要不要裁剪等 |

### 1.2 先看画师的使用规则

很多画师在 **Pixiv 个人简介**或**作品说明**里写了规则，先看清楚。常见写法：

| 写法 | 意思 |
| --- | --- |
| 無断転載禁止 / 禁止转载 | 不许擅自转发、搬运 |
| 無断使用禁止 / 加工禁止 | 不许擅自使用、修改 |
| AI学習禁止 | 不许拿去训练 AI |
| 商用利用不可 | 不许商用 |
| 自作発言禁止 | 不许说成是自己画的 |
| 個人利用OK / 壁紙OK | 个人使用（如做壁纸）可以，但通常**仍不允许再传播** |

规则写了「不行」的，就不要用；没写的，**也要去问**，不能默认可以。

### 1.3 联系画师

可以用下面这些方式联系：

- Pixiv 私信：画师主页 →「发送消息」（有的画师关闭了私信）。
- 画师在简介里留的 X（Twitter）、微博、Bilibili、邮箱等。
- 有的画师开放了约稿或授权渠道（Skeb、米画师等），按他们的流程走。

说清楚三件事：**用在哪、怎么改、会不会传播**。下面是三个模板，按画师常用的语言选一个，改成你的情况。

### 1.4 记住这几点

- **保留授权记录**（聊天截图等），以防以后有疑问。
- 画师只同意「自用」，就**不要**把放了图的插件打包发给别人，也不要发带这张图的截图。想发截图要另外问。
- **不要擦掉画师的签名或水印**，除非画师明确同意。
- 画师不同意或没回复，就换一张图，或者干脆不放。

## 第 2 步：下载原图

只下载已经**得到同意**的作品。

1. 登录 Pixiv，打开清单里的原作页面。
2. 点一下图片，进入大图查看；再点一次会显示**原图**（最清晰的版本）。
3. 在原图上**右键 →「图片另存为」**，存到你自己的文件夹，例如 `D:\主题插画\`。
4. 一个作品有多张图时，页面上会显示「1/2」之类的页码。清单备注写了「用第 2 张」的，就翻到第 2 张再保存。

> 小提示：保存时文件名可以随便，后面会重新命名。建议在 Windows 资源管理器里打开「查看 → 文件扩展名」，免得看不出文件到底是 `.jpg` 还是 `.png`。

## 第 3 步：把图放进插件

三种方法，按你的情况选：

| 方法 | 能换哪些图 | 难度 |
| --- | --- | --- |
| [A. 在设置里上传](#方法-a在设置里上传最简单) | 只能换**背景图**（还支持 GIF、MP4/WebM 视频） | ★ 最简单 |
| [B. 用自带脚本转换](#方法-b用自带脚本转换推荐) | 全部：背景、启动画面、Q 版、立绘 | ★★ 需要装 Python |
| [C. 手动转换后放进去](#方法-c手动转换后放进去) | 全部 | ★★ 不用装东西，但要自己注意细节 |

### 方法 A：在设置里上传（最简单）

1. 打开 DSH → 左下角「设置」→ 左栏「鸣潮主题」。
2. 在皮肤列表里**点选**要换背景的那套皮肤。
3. 往下找到「背景图」，点「**换一张**」，选你下载的图片。
4. 马上就会生效，不用重启。想换回来就点「**恢复默认**」。

上传的图存在你电脑的 `%APPDATA%\dsh-carlotta-theme\` 里，不会改动插件目录，重装插件也还在。
这个方法**换不了启动画面、Q 版和立绘**，这几种请用方法 B 或 C。

### 方法 B：用自带脚本转换（推荐）

脚本 `tools/prepare.py` 会自动：按清单裁剪（比如去掉画框）→ 缩到合适大小 → 转成 WebP → 用正确的文件名放到正确的位置；Q 版和立绘还会把白底变成透明。**它不会联网，也不会下载任何东西。**

**① 安装 Python（只需一次）**

1. 打开 <https://www.python.org/downloads/> 下载 Python 3（3.9 或更新）。
2. 安装时**勾选「Add python.exe to PATH」**，然后点「Install Now」。
3. 按 `Win + R`，输入 `powershell` 回车，在打开的窗口里输入下面这行，回车，安装图片库 Pillow：

```powershell
pip install pillow
```

**② 进入插件目录**

在 PowerShell 里输入（把路径换成你克隆插件的位置）：

```powershell
cd "D:\dsh-carlotta-theme"
```

**③ 看看有哪些位置**

```powershell
python tools/prepare.py list
```

会列出全部 70 个位置，`[有]` 是已放的，`[缺]` 是还没放的，后面是原作链接。

**④ 转换一张图**

格式是 `python tools/prepare.py 你下载的图片 位置名`。例如把西格莉卡「符文」的背景放进去：

```powershell
python tools/prepare.py "D:\主题插画\142480181_p0.jpg" bg/srune
```

看到 `已保存 assets/bg/srune.webp` 就成功了。位置名就是清单「放到」那一列去掉 `assets/` 和扩展名，例如：

| 清单里的「放到」 | 位置名 |
| --- | --- |
| `assets/bg/srune.webp` | `bg/srune` |
| `assets/boot/dveil.webp` | `boot/dveil` |
| `assets/img/chibi-sigrika.png` | `img/chibi-sigrika` |

不想要自动裁剪，就在最后加 `--no-crop`。

### 方法 C：手动转换后放进去

不想装 Python，也可以自己转换，但要注意：

1. **格式和文件名必须完全一致**，包括扩展名。背景图和启动画面都是 `.webp`；Q 版是 `.png`（立绘是 `.webp`），都要**透明底**。
2. **转 WebP**：可以用浏览器打开 <https://squoosh.app/>（图片在你自己浏览器里处理，不会上传），把图拖进去，右边格式选「WebP」，质量 85 左右，下载。也可以用 Photoshop、GIMP、XnConvert 等软件。
3. **建议尺寸**（最长边）：

   | 种类 | 文件夹 | 建议最长边 | 说明 |
   | --- | --- | --- | --- |
   | 背景图 | `assets/bg/` | 2560–2880 像素 | 横图最好（16:9 或更宽）；单张最好别超过 1 MB |
   | 启动画面 | `assets/boot/` | 2000–2400 像素 | 竖图或方图都行，显示在画面右侧 |
   | Q 版 | `assets/img/chibi-*.png` | 300–600 像素 | 透明底 PNG |
   | 立绘 | `assets/img/fullbody-*.webp` | 1300–1400 像素（高） | 透明底 WebP |

4. 清单备注里写了「裁掉画框 / 白边」「用第 2 张」的，要自己裁好。
5. 把文件放进插件目录对应的文件夹，例如 `D:\dsh-carlotta-theme\assets\bg\srune.webp`。

## 第 4 步：让 DSH 读到新图

DSH 安装插件时会**复制一份快照**，所以改了 `assets` 里的图以后，光重启是看不到的，要重新安装一次：

1. DSH → 设置 → 插件 → 找到「鸣潮主题」→ **移除**。
2. 点「添加插件」，填插件目录的完整路径（例如 `D:\dsh-carlotta-theme`）。
3. **重启 DSH**。
4. DSH 自带的「正在启动」页面要**再重启一次**才会换成新的启动图。

（方法 A 在设置里上传的背景不需要这一步。）

## 第 5 步（可选）：调整构图和署名

每套皮肤的背景位置是按清单里那张原图调好的。你换成构图不同的图时，可能出现「标题挡住人脸」或「人物太大」，可以改 `lib/client.js` 里对应皮肤的参数（用记事本或 VS Code 打开，按 `Ctrl + F` 搜皮肤名，例如 `符文 · 语义解现`）：

```js
bg: { size: "cover", pos: "100% 40%", zoom: 1.15, origin: "100% 40%" },
```

| 参数 | 作用 | 常用值 |
| --- | --- | --- |
| `size` | 怎么铺满 | `"cover"` 铺满全屏；`"auto 100%"` 按高度放、靠一边 |
| `pos` | 图片对齐位置（横、竖） | `"center 40%"`、`"0% 40%"` 靠左、`"100% 40%"` 靠右 |
| `zoom` | 放大倍数 | `1` 不放大；`1.2` 放大 20% |
| `origin` | 从哪个点放大 | `"0% 40%"` 人物往右挪；`"100% 40%"` 人物往左挪 |

首页标题大约在画面横向 52%–68% 的位置，让人脸落在这个范围之外就不会被挡住。

启动画面的参数在同一套皮肤的 `boot: { ... }` 里：

| 参数 | 作用 |
| --- | --- |
| `mode` | `"portrait"` 竖图显示在右侧；`"full"` 横图铺满 |
| `w` | 竖图模式下图片占画面宽度的百分比，例如 `36` |
| `credit` | 启动画面右下角显示的**画师署名**，换了图请改成新图的画师 |

改完 `client.js` 同样要按第 4 步移除再添加插件。

## 常见问题

**放了图还是纯色背景？**
- 检查文件名和扩展名是否和清单**完全一样**（`srune.webp` 不能写成 `srune.webp.jpg` 或 `Srune.webp`）。
- 检查是不是放进了插件目录里的 `assets\bg\`，而不是别的地方。
- 改完要按[第 4 步](#第-4-步让-dsh-读到新图)移除再添加插件，并重启。

**启动画面还是旧的？**
DSH 自带的启动页要重启两次才换；插件里切换皮肤时播放的启动画面，重新添加插件后就会更新。

**图片很大，打开 DSH 变慢？**
用方法 B 的脚本会自动压缩；手动转换时把最长边缩到上面表格的建议值，WebP 质量 80–86。

**Q 版 / 立绘周围有白边？**
需要透明底的图。方法 B 的脚本只能去掉贴着四边的纯白背景；背景复杂的图请用抠图工具处理，或请画师提供透明底版本。

**画师不同意，或者一直没回复？**
那就不要用这张图。可以换成别的、你有权使用的图，或者干脆不放，主题照样能用。
