# 图片清单（原作链接与 ID）

> **本仓库不包含下面任何一张图片。** 这里只列出主题作者当初参考使用的原作页面，方便你找到原作者、向原作者申请授权。
> 插画版权归各位画师所有。**在下载、使用（包括只放进自己电脑的插件里自用）、修改（裁剪、抠图、转格式）或传播之前，必须先取得原作者的同意。** 详见 [免责声明](../README.md#免责声明) 和 [插图教程](插图教程.md)。

- 「放到」一列是插件里的文件路径（相对于插件目录），文件名和扩展名必须完全一致。
- 「作品 ID」就是 Pixiv 作品编号，原作页面是 `https://www.pixiv.net/artworks/作品ID`。
- 同一个作品有多张图时，默认用第 1 张；用其他张的会在备注里写明。
- 也可以完全不用这些图，换成你自己有权使用的任何图片。
