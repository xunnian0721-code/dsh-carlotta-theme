# 插画素材（需自行准备）

出于版权原因，仓库里不带画师的插画。把图片按下面的文件名放进来，重启 DSH 即可生效；
少哪张，对应位置就只显示纯色背景。也可以不放，直接在「设置 → 珂莱塔主题 → 背景图」给每套皮肤上传自己的图。

格式：webp / png / jpg 都行，但**文件名（含扩展名）必须一致**；建议宽 1920–2200 像素。

| 文件 | 用在哪 | 建议构图 |
| --- | --- | --- |
| `bg/night.webp` | 夜宴 · 背景 | 横图，暗色，人物偏右 |
| `bg/day.webp` | 白昼 · 背景 | 横图，亮色，人物偏左 |
| `bg/prism.webp` | 璀璨 · 背景 | 横图，暗色，人物偏右 |
| `bg/daily.webp` | 休憩日 · 背景 | 竖图，靠右显示 |
| `bg/summer.webp` | 盛夏 · 背景 | 竖图，靠右显示 |
| `boot/night.webp` | 夜宴 · 启动画面 | 横图，文字在底部居中 |
| `boot/day.webp` | 白昼 · 启动画面 | 横图，人物在左，文字在右 |
| `boot/prism.webp` | 璀璨 · 启动画面 | 横图，人物居中偏左，文字在右 |
| `boot/daily.webp` | 休憩日 · 启动画面 | 宽横图（约 2:1），人物在右 |
| `boot/summer.webp` | 盛夏 · 启动画面 | 竖图，显示在右侧 |
| `img/chibi.png` | 侧栏 Q 版（透明底） | 约 400×400；没有时显示徽章 |
| `img/fullbody.webp` | 设置页右下角立绘（透明底） | 竖图 |

启动画面右下角的画师署名写在 `lib/client.js` 的 `SKINS.*.boot.credit`，换图后记得改成对应画师。
