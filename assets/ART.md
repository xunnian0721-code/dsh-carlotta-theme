# 插画素材说明

本目录里的插画都是作者用本地模型生成的**非商业同人图**：

- 模型：Anima base v1.0 + e20 LoRA（ComfyUI 本地运行）
- 流程：文生图出候选 → 人工挑选 → 1.5 倍放大并轻度重绘（重绘强度 0.32）→ Q 版和立绘抠成透明底
- 内容限定全年龄，人物不持武器

它们不是《鸣潮》官方素材，也不取自任何画师的作品。珂莱塔及《鸣潮》相关角色形象的知识产权归库洛游戏所有；本插件遵循库洛《鸣潮》同人创作指引（1.1 版），仅限个人非商业使用，**插画不适用仓库的 MIT 许可**，请勿用于商业用途。

## 换成自己的图

想用别的图：按上表的文件名替换（webp / png / jpg 都行，但文件名和扩展名要一致），然后在 DSH 插件页移除再重新添加插件。
也可以不改文件，直接在「设置 → 珂莱塔主题 → 背景图」给每套皮肤上传自己的图片、GIF 或视频。

启动画面角落的署名写在 `lib/client.js` 的 `SKINS.*.boot.credit`，换图后记得改成对应作者。
